博客还是太难写了啊啊啊啊啊啊啊啊！

折腾了大概两三天，试了好几个不同的风格，终于选到了一个比较满意的主题。看着自己搭建的博客慢慢成型，还是挺有成就感的。

既然配置了这么多内容，为了防止自己以后忘记，也为了帮助像我一样的新手，顺便出个简易教程吧。

博客搭建简易指南

1. 环境部署

首先是基础环境的准备，这是万丈高楼平地起的第一步。你需要安装以下三个核心工具：

  • Git: 用于版本控制和将代码推送到仓库。
  • Node.js: Hexo 是基于 Node.js 的，所以必须安装。建议安装 LTS（长期支持）版本。
  • Hexo: 博客的核心框架。

安装完 Node.js 和 Git 后，打开终端（cmd 或 PowerShell），输入以下命令全局安装 Hexo：

npm install -g hexo-cli

2. 初始化与主题配置

从默认主题开始

找一个文件夹，初始化你的博客目录：

右键打开控制台，我比较喜欢用git的

bash

hexo init myblog
cd myblog
npm install

克隆主题库

默认的主题虽然经典，但不够个性化。找到你喜欢的主题（比如 Butterfly, NexT 等），通常在主题的 GitHub 仓库都有说明。一般是将其克隆到 themes 目录下：

bash

# 示例：克隆某主题到 themes/theme-name 目录
git clone https://github.com/user/theme-name.git themes/theme-name

配置生效

修改博客根目录下的 _config.yml 文件，找到 theme 字段，将其修改为你刚才下载的主题文件夹名称：

YAML

theme: theme-name

3. 个性化定制

这一步是最花时间的，也是最有趣的。

修改自定义内容

你可以修改主题目录下的配置文件（通常是 _themes/theme-name/_config.yml）。在这里你可以设置：

  • 头像与作者名: 换上你帅气的头像。
  • 导航菜单: 设置首页、归档、标签等页面。
  • 社交链接: 添加你的 GitHub、Bilibili 等链接。

添加点击特效

为了让博客看起来更炫酷，我加了一些鼠标点击特效。通常是在页面的 footer 或者特定的 JS 文件中引入脚本。

例如：点击出现爱心、烟花或者文字效果。

添加悬浮卡片的图形链接

侧边栏或者首页的悬浮卡片可以增加互动性。这通常需要配置 HTML/CSS 或者在主题配置文件的 widgets 部分进行设置，将图标与你的跳转链接绑定。

虽然折腾的过程很痛苦，遇到报错会抓狂，但看到成品的那一刻，一切都值了！接下来的目标就是坚持更新（希望能做到吧 😂）。
